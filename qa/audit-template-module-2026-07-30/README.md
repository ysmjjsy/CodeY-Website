# 模板模块复核

日期：2026-07-30

## 结论

当前视觉层和主流程已经可用：上传入口直接打开文件选择器；模板列表按包 ID 聚合；审核记录、待审核队列和角标已经形成统一入口。

正式开放审核前仍需处理以下问题：

1. 审核弹框只展示标题、提交者、包版本、提交时间和权限，审核人无法查看文件、README、变更说明、版本差异或待审核包本身。
2. 当前已发布 Skill 的文件索引没有回填。Obsidian 包实际包含 `SKILL.md` 和 `_meta.json`，API 中的 `resources[].files` 仍为空，页面因此显示为“外部依赖”。
3. “我的模板”以最新提交覆盖整个模板状态。较新的拒绝或待审核版本会遮住仍然有效的已发布版本。
4. 防重复依赖应用层先查后写，没有数据库唯一约束，并发提交仍可能产生两条待审核记录。
5. 移动端保留 820px 宽表格，状态和操作需要横向滚动才能看到。
6. 次要文字使用约 10.5–12px 的浅灰色，实测与白色背景对比度约 2.56:1；审核页签也没有方向键切换逻辑。
